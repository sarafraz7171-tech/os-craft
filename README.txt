OS CRAFT - Command Guide
========================

Files:
- index.html       Home page
- commands.html    Categorized command reference
- style.css        Shared responsive theme
- script.js        Search and copy interactions

How to use:
1. Upload all files to the root of your GitHub Pages repository.
2. Open index.html as the homepage.
3. The commands page is available from the top navigation.

Important accuracy note:
The guide includes commands previously identified in the OS CRAFT project and common Minecraft/Paper commands.
It does not claim to contain every installed plugin command. Unknown bank, shop, house, business, transport and admin
commands are intentionally left unlisted rather than invented. Run /help in-game and compare the output to verify
the commands actually registered by the current server.

This guide intentionally does not include WorldEdit or WorldGuard commands.
